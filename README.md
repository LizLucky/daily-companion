# 하루곁

하루곁은 몸과 마음의 상태, 오늘 할 일, 식사, 물 마시기, 목표와 하루 기록을 한곳에서 관리하는 개인용 웹앱입니다.

## 사용 방법

`index.html`을 브라우저에서 열고 원하는 내용을 입력하거나 버튼을 누르면 됩니다. 입력한 내용은 서버가 아니라 현재 브라우저의 `localStorage`에 저장됩니다. 따라서 다른 기기나 다른 브라우저에는 자동으로 옮겨지지 않으며, 브라우저 데이터를 지우면 기록도 함께 사라질 수 있습니다.

## GitHub Pages

저장소의 GitHub Pages 설정에서 배포 원본을 기본 브랜치의 루트 폴더로 선택하면 정적 웹사이트로 게시할 수 있습니다.
